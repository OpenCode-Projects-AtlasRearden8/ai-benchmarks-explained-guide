# 00 — Start Here

Welcome. This guide has one job: to help you read AI model rankings the way a
careful reader reads a nutrition label — not overwhelmed, not fooled, and
knowing exactly what the numbers *can* and *cannot* tell you.

## Who this is for

You, if any of these sound familiar:

- You've seen headlines like "New model tops MMLU at 90%!" and wondered what
  that actually means for *you*.
- You're choosing between a cloud AI subscription and a model you can run on
  your own computer (say, with [Ollama](glossary.md#ollama)), and the
  leaderboard isn't helping.
- You'd like to be skeptical in a *useful* way — not cynical, not gullible.

No math required. Where arithmetic appears, it's addition and rounding.

## The one idea the whole guide rests on

> **A benchmark score is a measurement, not a promise.**

It tells you how a model did on one test, created by one group of people, with
one set of assumptions, at one point in time. That's useful information — the
same way a flashlight is useful at night. It is not flood lighting. When a
marketing page shows you one giant number, the sentence you should hear in
your head is: *"one measurement, one moment, one test."*

## What this guide will not do

- **It will not tell you which model to buy.** Models change constantly; the
  skill of reading rankings outlasts any specific ranking.
- **It will not repeat vendor hype.** Where the guide uses example numbers,
  they come from fictional models (like "Checkers-7B") clearly marked as
  illustrations.
- **It is not safety or medical advice.** It is education only. If you're a
  healthcare worker exploring AI, treat this as background reading — never as
  clinical guidance. Nothing here replaces your professional judgment.

A note on tone: we promise not to be condescending. If a term sounds jargony,
it will be decoded in plain English — usually the same page it first appears
on. Every underlined term on the website is a glossary link on purpose.
